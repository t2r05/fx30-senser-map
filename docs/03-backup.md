# 备份数据结构

`0x603 / cmd 0x05`（对应 PMCA 的 `BACKUP_PDT_READ`）在 FX30 Ver.6.00 上返回 **2,253,564 字节**完整备份数据。

---

## 一、获取方式

```python
hdr = CommandHeader.pack(category=0x603, command=0x05)
res, data = device.sendSenserPacket(SONY_PFUNC_AdjustControl, hdr + b'')
# res == 0, len(data) == 2253564
```

**不需要参数**，无需先 select 路径。一次调用返回全量。

保存为文件后，可用 PMCA 的 `print_backup` 解析：

```bash
python pmca-console.py print_backup backup.bin > backup_all.txt
```

输出格式：

```
id=0x00050000, size=0x0004, attr=0x00:
  00 00 00 00                                      ....
```

---

## 二、头部特征

文件起始字节（前 32 字节）：

```
00 00 00 04 | aa aa aa aa | 01 01 00 00 | 42 4b 34 00 | 33 03 00 00 | 8b 8b 00 00 | 80 59 03 00 | e0 cb 09 00
```

- `00 00 00 04`：头部标记（4）
- `aa aa aa aa`：填充
- **`42 4b 34 00` = `"BK4\0"`** — 备份格式标识（Backup v4）

## 三、属性规模

解析出 **25,737 个属性**，其中约 **17,833 个**为「size 1–4 且值 ≤ 16」的枚举型。

按 ID 高 16 位分段的主要聚集：

| 段 | 属性数（枚举型） |

## 四、⭐ ID 布局与 PMCA 定义同构（锚点验证）

这是本次测绘最有用的结论：**PMCA 对老机型的属性 ID 定义，在 FX30 上语义一致**。

| ID | PMCA 名称 | FX30 实测值 | 判定 |
|---|---|---|---|
| `0x003e0005` | `modelName` (16B) | `ILME-FX30` | ✅ |
| `0x00e70000` | `modelCode` (5B) | 与 `info` 命令的「产品代码」一致 | ✅ |
| `0x00e70003` | `serialNumber` (4B) | 与 `info` 命令的「序列号」一致 | ✅ |
| `0x003c0373` | `recLimit` | `0x0d` = 13（电影机无 30 分钟限制） | ✅ |
| `0x003c04b6` | `recLimit4k` | `0x0c` = 12 | ✅ |

**老平台特有属性在 FX30 上按平台特性缺席**，这本身也是一致性的旁证：

| ID | PMCA 名称 | FX30 |
|---|---|---|
| `0x01660024` | `androidPlatformVersion` | **不存在**（FX30 是纯 Linux，无 Android 子系统） |
| `0x01070148` | `palNtscSelector` | **不存在** |
| `0x01640001` | `usbAppInstaller` | **不存在**（无 PMCA 应用商店） |

**含义**：可以按 ID 段外推语义——例如 `0x003c` 段是「功能限制区」（录制时长限制就在此段），`0x0107` 是制式、`0x010d` 是语言。

## 五、写入命令（本仓库未使用）

| 操作 | 命令 | 说明 |
|---|---|---|
| 读全量 | `0x603 / 0x05` | 已实测 |
| 读状态 | `0x603 / 0x06` | 52 字节，含备份区域代号 |
| **写单个属性** | `0x603 / 0x02` | PMCA `BACKUP_WRITE`，参数格式未解（实测恒 129） |
| **写预设块** | `0x603 / 0x04` | PMCA `BACKUP_PDT_WRITE` |
| 落盘/应用 | `0x603 / 0x03` | PMCA `BACKUP_SAVE`（空 payload 返回 0） |

⚠️ **备份区写坏可能影响相机启动，该层风险未评估。** 若要尝试，务必先留完整原始备份，并确认官方 `BODYDATA.DAT` 能否覆盖恢复。
