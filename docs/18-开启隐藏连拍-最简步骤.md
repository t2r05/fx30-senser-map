# 一键开启 FX30 隐藏连拍 —— 最简步骤

> 面向使用者。**照做即可，不需要理解原理。**
> 需要理解原理请看 [`docs/11-drive-mode-ids.md`](11-drive-mode-ids.md) 与仓库 README 的「进展补充 · 六」。

---

## 一、最简流程（4 步）

### 第 1 步 · 准备

- 相机 USB 模式设为 **海量存储器**（Menu → 网络/USB → USB 连接 → 海量存储器）
- 插好 Type-C 线
- 电量 ≥ 50%
- 电脑已装好驱动（`054C:0E0E` 与 `054C:0336` 都装 **libusbK**，用 Zadig）

### 第 2 步 · 一条命令

```bash
python tools/probe_drive_write.py --burst
```

看到这两行就成功了：

```
  0x08EF80 读回 0x01  ★ 已生效
  0x091690 读回 0x01  ★ 已生效
```

### 第 3 步 · 冷启动（**关键，不要省**）

1. 拔掉 USB 线
2. **取出电池，等 ≥30 秒**
3. 装回电池，开机

> ⚠️ **关机再开机不算冷启动！** 那叫热重启，走 `nflasha5` 暖启动镜像恢复路径，
> 会把刚才的改动吃掉，你会误以为方法无效。**必须拔电池。**

### 第 4 步 · 验证

- 驱动模式菜单显示 **「连拍」**
- 按住快门，能连续拍摄

## 二、三条命令走天下

| 命令 | 作用 |
|---|---|
| `python tools/probe_drive_write.py --burst` | **开启连拍** |
| `python tools/probe_drive_write.py --single` | 回滚成单张 |
| `python tools/probe_drive_write.py --probe` | 只看当前状态，**不写任何数据** |

---

## 三、你必须知道的两件事

### 1. 这是隐藏模式 —— 手动切菜单会掉回

连拍**不在驱动模式菜单的选项列表里**。一旦你手动去切换驱动模式，
固件会把设置重置回单张（`0x8EF80` 和 `0x91690` 都被写回 `0x00`）。

⇒ **掉了就重新跑一次 `--burst`**，重新冷启动。就这么简单。

### 2. 两个字段必须成对写

设置区里这两个字节是**同一个设置的两层表示**，缺一个就会被固件回退：

| 偏移 | 值 | 含义 |
|---|---|---|
| `0x8EF80` | `0x01` | `EXTERN_VAL_DRIVE_MODE_BURST`（外层菜单枚举） |
| `0x91690` | `0x01` | `DRIVE_MODE_CONT_SHOOTING`（内层驱动枚举） |

**只写其中一个 → 相机仍是单张。** 这是本项目踩过的最大的坑，
早期「写了没生效」的负结论就是这么来的。

## 四、其它预设（谨慎使用）

```bash
python tools/probe_drive_write.py --single     # 单张（回滚）
python tools/probe_drive_write.py --bracket    # 包围曝光
python tools/probe_drive_write.py --timer2     # 自拍定时 2 秒
python tools/probe_drive_write.py --timer5     # 自拍定时 5 秒
python tools/probe_drive_write.py --timer10    # 自拍定时 10 秒
```

| 预设 | `0x8EF80` | `0x91690` | 验证状态 |
|---|---|---|---|
| `--single` | `0x00` | `0x00` | ✅ 已验证 |
| `--burst` | `0x01` | `0x01` | ✅ 已验证 |
| `--bracket` | `0x02` | `0x09` | 🟡 实测过该组合，未验证写入效果 |
| `--timer2` | `0x08` | `0x05` | ✅ 实测过该组合 |
| `--timer5` | `0x0C` | `0x05` | 🟡 按表推测 |
| `--timer10` | `0x07` | `0x05` | 🟡 按表推测 |

🟡 的请自行承担风险，出问题用 `--single` 回滚。

## 五、安全

- 🟡 **这是写操作**，会改相机设置区。写前自动存一份完整快照
  `dump/drive_before_<时间戳>.bin`（2.25 MB），**永不覆盖历史**。
- 只写 `/setting` 设置区，**不碰固件分区**。
- 出问题：恢复出厂设置，或把 `drive_before_*.bin` 写回。
- **不要手写 `0x08DC14` / `0x07A640`** —— 那是运行时噪声，不是模式字段。
- 完整风险分级见 [`docs/17-disclaimer-and-boundaries.md`](17-disclaimer-and-boundaries.md)。

## 六、FAQ

**Q：为什么菜单里没有连拍这个选项？**
A：它是隐藏模式，菜单不列出该选项，所以手动一切换就掉回。这是已知行为，
能否让菜单正常显示仍在研究中。

**Q：我拔电池了但没变？**
A：确认三点：① 是真的取出了电池（不是关机）；② 等待 ≥30 秒；
③ 刷入时看到「★ 已生效」两行。三者都有还不行就跑 `--probe` 看当前值。

**Q：`--probe` 显示 `0x8EF80=0x00` 但我明明刷过？**
A：很可能是你中途手滑切了菜单，固件已重置。重新 `--burst` 即可。

**Q：连拍速度是多少？能调吗？**
A：尚未确定。`DRIVE_MODE_CONT_SHOOTING_OPTION_{HI_PLUS,HI,MID,LOW}` 存在于固件，
但 FX30 的 `customFps_Elec_*` 零命中（疑似机型裁剪），调节方式待研究。

**Q：这会影响保修吗？**
A：可能。请只在自有设备上操作，风险自负。详见 [`docs/17`](17-disclaimer-and-boundaries.md)。
