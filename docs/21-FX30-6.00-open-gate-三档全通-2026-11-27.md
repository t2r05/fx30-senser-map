## 2. 6.00 适配：为什么需要 relink

- 社区 kit 的 design 全部按 **6.01 libmpr**（`2ba4e927…`，3,517,008 B）编地址；本机是 **6.00**（`8f37bc75…`，3,500,624 B）。
- 传感器（L5）、输出尺寸（L16）、屏幕（N97）三步在 6.00 上**地址一致，直接可用**。
- 编码器步（L19）guard 拒绝 → 本地重建 **N102**：
  - av-cam 部分取 A6700 contributed full design（−0xf90 映射）；
  - libmpr 行：MP4 height 站点 **−0x19b8**、`g_videoParamComb` **−0x3d00**；
  - ziglang 0.16.0 编译，SHA `b6d009db…`。
- **N102 覆盖原 N98 的全部 101 个 av-cam 站点**（dump：`av-cam 0 stock, 101 target`），之后不再需要 N98。
- 顺序不可换：**N102 必须第一个打**（guard 要求 `lm 0x21ff60` 为 stock）。

```bash
for step in N102 L5 L16 N97; do
  "$PY" -B fx30_run.py $step --go --writes-memory --firmware-shown 6.01
done
```

## 3. HS 4K 为什么原来会重启

- FX30 官方编码器 design 的 29 个描述符**全是 23.98p / 25p，没有 50p**。
- 而 PAL 的 **XAVC HS 4K 只有 50p** ⇒ 描述符高度 2160 vs 实际帧 2560 错配。
- 切换格式本身无害（实时显示已是 3:2）；**一按录制、HEVC 通道初始化时**才黑屏重启 —— 与社区 issue #10 现象一致。
- 补 A6700 contributed **p50 组**（height 2560、`UseCore=2`、level 153→180）即通。
- 副产品：3840×2560 = 9.83 MP，HEVC Level 5.0/5.1/5.2 上限 8.91 MP，**只有 L6.0 合规**；contributed 的 level 180 恰好正确。

## 4. 零裁切（定量）

同机位同场景，各抽一帧 → 640×427 灰度 → 中心缩放搜索（0.90–1.10，步长 0.0025）+ FFT 相位相关 + NCC（`scripts/fov_compare.py`）：

| 对比 | best scale | NCC | 位移 |
|---|---|---|---|
| 25p AVC → 50p AVC | **1.0000** | 0.975 | (−1, 0) px |
| 25p AVC → 50p HS | **1.0000** | 0.952 | (0, 0) px |

scale = 1.0000 ⇒ **50p 相对 25p 没有裁切**，视场一致。

## 5. 电力保持窗口（社区未决问题，本机实测）

| 动作 | 结果 |
|---|---|
| 关机 → **≈10 s 内**再开机 | **补丁仍在**，继续 open gate |
| 关机 → 等 **>≈10 s** 再开机 | 补丁清除，回 3840×2160 |
| 拔电池（10 s） | 清除 |
| 死机自动重启 | 清除 |

⇒ FX30 的电源开关不是"保留/清除"二选一，而是**与待机放电赛跑**：10 s 内 RAM 内容还在，超过即丢。这也解释了社区 #8 / #9 同一开关不同结果。
⇒ 要"干净复位"，关机等 10 s 即可，比拔电池更安全。

## 6. 已知缺口：XML 侧车仍是 16:9

MP4 的 `tkhd` 已是 3840×2560，但同目录 `*M01.XML` 仍写：

```xml
pixel="3840" numOfVerticalLine="2160" aspectRatio="16:9"
<VideoFrame videoCodec="AVC_3840_2160_HP@L51" .../>
```

依赖 Sony XML 的工作流（Catalyst、部分 NLE）会显示 16:9。**MP4 正片无影响**。已作为离线课题交服务器（见 `internal/decisions/HANDOFF-2026-11-27-server-cardspeed600-xml-writer.md`）。
